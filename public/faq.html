Frequently Asked Questions

Everything you've ever wanted to know about MindMaster, answered.

🔍
🎮 General
MindMaster is a competitive trivia quiz game built as a full-stack web application. It features a global leaderboard, 30+ questions across multiple categories, and a sleek Kuizu-inspired interface. Sign up, play 5-question rounds, and compete with players worldwide.
Yes, completely free. Create an account with your email and you have unlimited access to all games, the global leaderboard, and all features. No premium tiers, no ads, no paywalls.
No downloads needed. MindMaster is a web-based application that runs entirely in your browser. It works on any modern browser on desktop, tablet, or mobile.
🕹️ Gameplay
Each game round consists of exactly 5 questions. Questions are randomly selected and shuffled from a pool of 30+ questions, so no two rounds are the same. All four answer options are also shuffled randomly.
You earn 10 points for each correct answer. With 5 questions per round, the maximum score per game is 50 points. Wrong answers score 0 (no penalty). Your personal best score is what appears on the leaderboard.
The current version does not enforce a strict time limit per question. Take your time to think and answer correctly — accuracy is what matters for your score and leaderboard position.
Absolutely! You can play as many rounds as you like. After the game over screen, click "Play Again" to start a fresh round with newly shuffled questions. Each game is a new opportunity to beat your personal best.
👤 Account
At this time, display names are set during registration and cannot be changed. Choose carefully — your display name is your identity on the global leaderboard! Account profile settings are on the roadmap for a future update.
Password reset via email is planned for a future release. Currently, if you forget your password, you would need to create a new account. We recommend using a password manager to keep track of your credentials.
Account deletion is on the roadmap. Your data is stored securely in MongoDB and is never sold or shared. For urgent data removal requests, contact the admin.
⚙️ Technical
Your password is never stored in plain text — it's hashed using Bcrypt with a salt factor of 10. Sessions are managed via JWT tokens stored in your browser's localStorage. All API routes handling sensitive data require a valid token.
MindMaster works on all modern browsers: Chrome, Firefox, Edge, Safari, and mobile browsers. We recommend Chrome or Edge for the best experience. Internet Explorer is not supported.
Backend: Node.js + Express.js REST API
Database: MongoDB with Mongoose ODM (hosted on Atlas)
Authentication: JWT (JSON Web Tokens) + Bcrypt
Frontend: HTML5, CSS3 (vanilla), Vanilla JavaScript (ES6+)
File Storage: Multer for file uploads
Markdown: Marked.js for the vault editor
