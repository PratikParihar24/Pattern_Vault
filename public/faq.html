Frequently Asked Questions

Everything you've ever wanted to know about MindMaster, answered.

🔍
🎮 General
MindMaster is a competitive trivia quiz game built as a full-stack web application. It features a global leaderboard, 30+ questions across multiple categories, and a sleek Kuizu-inspired interface. Sign up, play 5-question rounds, and compete with players worldwide.
Yes, completely free. Create an account with your email and you have unlimited access to all games, the global leaderboard, and all features. No premium tiers, no ads, no paywalls.
No downloads needed. MindMaster is a web-based application that runs entirely in your browser. It works on any modern browser on desktop, tablet, or mobile.
🔐 Pattern Vault
The Pattern Vault is an end-to-end encrypted (E2EE) secret storage area embedded inside MindMaster. It allows logged-in users to securely write, encrypt, store, and view private markdown notes using zero-knowledge client-side encryption.
There are two ways to open the vault while logged in:

1. QWERTY Sequence (Mobile & All Devices): Answer quiz options matching your email address's secret 5-question QWERTY pattern during a game round.
2. Keyboard Shortcut (Desktop/Developers): Press Ctrl + Shift + X anytime during a quiz round to open the vault interface instantly.
Once unlocked, you can type markdown text in the editor. Enter a private passphrase to encrypt your note locally using AES-GCM 256-bit encryption before saving. Only you holding your key can decrypt and read your vault contents.
No. MindMaster uses zero-knowledge client-side encryption. The server only receives encrypted cipher text. Without your secret passphrase, nobody—not even server administrators—can decrypt your notes.
🕹️ Gameplay
Each game round consists of 5 questions randomly selected from a pool of 30+ questions. All four answer options are shuffled every time.
You earn 10 points for each correct answer (max 50 points per round). Your personal best score is ranked on the global leaderboard.
👤 Account & Security
Passwords are hashed using Bcrypt (salt factor 10). Authentication sessions use secure JWT tokens. All sensitive API endpoints require valid authentication headers.
