Technical Foundation

Built with real-world tech

Every layer of MindMaster — from the database schema to the quiz animation — was hand-crafted. No frameworks doing the heavy lifting. Just clean, purposeful code.

🟢 Node.js 🚂 Express.js 🍃 MongoDB 🔷 Mongoose 🔐 JWT Auth 🔒 Bcrypt ⚡ Vanilla JS 🎨 CSS Variables 📝 Marked.js 📁 Multer
🏗️

RESTful Architecture

5 core API route groups: Auth, Vault, Groups, Pages, Albums + Leaderboard. Structured for scalability and clean separation of concerns.

🔐

Security First

JWT-based stateless sessions, Bcrypt password hashing, middleware-protected routes, and a custom pattern-based access control layer.

📱

Responsive by Design

Mobile-first layouts with CSS Grid, Flexbox, and custom responsive components. Works flawlessly from 320px to 4K.

System Design

How it all connects

🌐

Frontend (Public)

HTML5 + CSS3 + Vanilla JS. Landing, quiz game, leaderboard — all server-rendered static files. Zero build tools.

⚙️

Backend (API)

Node.js + Express serves both static files and REST API. JWT middleware protects private routes. Multer handles file uploads.

🍃

Database (MongoDB Atlas)

Mongoose schemas for Users, Groups, Pages, Albums. Relational references via ObjectId. Cloud-hosted for reliability.
